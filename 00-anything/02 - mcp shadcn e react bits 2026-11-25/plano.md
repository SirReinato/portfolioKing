# MCP shadcn e React Bits no portfolioKing

## Etapa 1 — Configurar e validar a consulta ao registry

- **Contexto e objetivo** — Disponibilizar no Codex o MCP oficial do shadcn e consultar itens do catálogo React Bits a partir do repositório.
- **Escopo** — Configuração de desenvolvimento do projeto. O portfólio usa JSX, Vite e styled-components. A tarefa não inclui instalar componentes nem mudar a estrutura de estilos.
- **Arquivos** — `.codex/config.toml`, `components.json`, `README.md`, `AGENTS.md` e este plano.
- **Passos técnicos** — Configurar o servidor no Codex do projeto, registrar `@react-bits` e consultar um item do catálogo pelo MCP. Documentar o uso e rodar Graphify, lint e build.
- **Dependências** — Node.js e npm, pacote oficial `shadcn` executado via npx e acesso HTTPS ao registry público.
- **Critérios de aceitação** — O Codex reconhece a configuração local, o servidor MCP consulta o catálogo React Bits e Graphify, lint e build passam.
- **Linear** — A busca pelo projeto `portfolioKing` não encontrou resultado. Este arquivo é o bloco copiável da demanda.
